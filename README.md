AI Resume Analyzer

An AI-powered web application that analyzes resumes, extracts key information, and provides intelligent feedback on candidate suitability, skills, and job-role matching.

🚀 Features

✅ Resume Parsing: Extracts key information (name, contact, skills, education, experience).
✅ AI-Powered Insights: Uses NLP to evaluate resume quality, keyword match, and relevance to job descriptions.
✅ Skill Matching: Compares candidate skills against job requirements.
✅ Scoring System: Generates a professional “Resume Score” based on AI analysis.
✅ PDF Upload Support: Upload resumes in PDF or DOCX format for instant analysis.
✅ User-Friendly UI: Clean and responsive design for smooth user experience.
